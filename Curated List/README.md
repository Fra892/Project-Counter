# 🧠 Algorithmic Problem Solving [1500 - 2100]

This document is a personal collection of competitive programming problems I have solved over time. Each entry includes a brief restatement of the problem, the extensive reasoning process that led to the solution, and the final code implementation.

### 📖 The Philosophy
**You will notice that the code is never commented.** This is an intentional choice. My goal is for readers to focus entirely on understanding the *reasoning* and the underlying logic provided in the text, rather than trying to reverse-engineer the solution from the syntax. 

### ⚙️ Structure & Ratings
* **Chronological Order:** Problems are presented in the order I solved them, without thematic categorization. This serves as a raw log to track technical progress and the consolidation of problem-solving skills.
* **Ratings:** The difficulty ratings range between 1500 and 2100. They are a blend of official Codeforces ratings, my own personal experience, and CLIST ratings (which I find mirror the general real-time performance of contestants perfectly).

### ⚠️ A Quick Recommendation
I hope that this material may be useful to others pushing through this rating bracket. However, I strongly recommend consulting my reasoning and code **only after making a genuine attempt** at solving the problems independently.
